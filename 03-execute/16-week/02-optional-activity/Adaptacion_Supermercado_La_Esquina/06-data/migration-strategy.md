# Estrategia de migración de datos

> Estado: 🟢 | Última actualización: 2026-07-05
> Autor: Andrés Felipe Castro Bedoya | Equipo: Andrés Felipe Castro Bedoya


## Situación actual

El supermercado "La Esquina" no cuenta con datos digitales previos: la información de ventas, inventario y fiados está en cuadernos y listas de precios físicas.

## Estrategia

1. Levantar el catálogo inicial de productos a partir de la lista de precios actual del negocio.
2. Registrar el stock inicial contando físicamente el inventario existente.
3. Registrar los fiados pendientes que existan al momento de iniciar a usar el sistema, para no perder ese historial.
4. A partir de la puesta en marcha, toda la información nueva se registra directamente en el sistema.
