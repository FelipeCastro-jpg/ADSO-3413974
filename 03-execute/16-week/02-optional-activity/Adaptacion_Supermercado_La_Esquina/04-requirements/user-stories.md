# Historias de usuario

> Estado: 🟢 | Última actualización: 2026-07-05
> Autor: Andrés Felipe Castro Bedoya | Equipo: Andrés Felipe Castro Bedoya


**HU-01** — Como cajero, quiero registrar una venta seleccionando productos, para calcular el total automáticamente y cobrar más rápido.

**HU-02** — Como administrador, quiero gestionar el catálogo de productos, para mantener precios y stock actualizados.

**HU-03** — Como administrador, quiero generar el corte de caja al final del día, para saber si el dinero físico coincide con lo vendido.

**HU-04** — Como cajero, quiero registrar una venta a crédito, para que el cliente pueda pagar después y quede como deuda registrada.

**HU-05** — Como cajero, quiero emitir un tiquete de venta, para entregarle un comprobante al cliente.

**HU-06** — Como administrador, quiero recibir una alerta de stock bajo, para reabastecer antes de quedarme sin producto.
