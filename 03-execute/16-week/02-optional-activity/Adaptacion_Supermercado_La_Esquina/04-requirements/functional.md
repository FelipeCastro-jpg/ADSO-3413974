# Requerimientos funcionales

> Estado: 🟢 | Última actualización: 2026-07-05
> Autor: Andrés Felipe Castro Bedoya | Equipo: Andrés Felipe Castro Bedoya


| ID | Requerimiento | Módulo |
|----|---------------|--------|
| RF-01 | El sistema debe permitir registrar ventas seleccionando productos y calculando el total automáticamente | POS |
| RF-02 | El sistema debe permitir agregar, editar y eliminar productos del catálogo | Inventario |
| RF-03 | El sistema debe descontar automáticamente el stock al registrar una venta | Inventario |
| RF-04 | El sistema debe generar cortes de caja diarios comparando dinero físico y registrado | Reportes |
| RF-05 | El sistema debe permitir administrar créditos (fiados) de clientes | Créditos |
| RF-06 | El sistema debe generar tiquetes de venta | Facturación |
| RF-07 | El sistema debe permitir gestionar usuarios con distintos roles (administrador, cajero) | Usuarios |
| RF-08 | El sistema debe alertar cuando el stock de un producto llegue al mínimo configurado | Inventario |
