# Patrones de comunicación

> Estado: 🟢 | Última actualización: 2026-07-05
> Autor: Andrés Felipe Castro Bedoya | Equipo: Andrés Felipe Castro Bedoya


No aplica en la versión actual del proyecto, ya que el sistema es monolítico y todos los módulos (ventas, inventario, créditos, reportes) se comunican dentro del mismo proceso, sin necesidad de llamadas entre servicios.

Si en el futuro se dividiera el sistema (por ejemplo, un servicio de inventario compartido entre sucursales), aquí se documentarían los patrones síncronos/asíncronos usados.
