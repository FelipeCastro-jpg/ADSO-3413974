## Principios

- Interfaz simple y con textos claros, pensada para usuarios sin experiencia tecnológica (cajeros y el propietario).
- Botones grandes y visibles para las acciones más usadas: registrar venta, buscar producto, cobrar.
- Colores de alerta (rojo/naranja) para stock bajo o errores; verde para confirmaciones.
- Tipografía legible en tamaño mediano-grande, pensando en pantallas pequeñas o de resolución básica.
