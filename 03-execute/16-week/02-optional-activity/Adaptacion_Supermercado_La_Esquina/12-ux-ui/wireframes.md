# Wireframes

> Estado: 🟢 | Última actualización: 2026-07-05
> Autor: Andrés Felipe Castro Bedoya | Equipo: Andrés Felipe Castro Bedoya


Pantallas principales a diseñar (bocetos de baja fidelidad):

1. **Login**: usuario, contraseña, botón de ingreso.
2. **Pantalla de venta (POS)**: buscador de productos, lista de productos agregados, total, botón de cobrar.
3. **Gestión de productos**: tabla de productos con opciones de agregar/editar/eliminar.
4. **Corte de caja**: resumen de ventas del día, total en sistema, campo para registrar el efectivo físico contado.
5. **Fiados**: lista de clientes con crédito pendiente, botón para registrar abono/pago.

> Los bocetos gráficos (imágenes) se deben guardar en [assets/images](../assets/images/) y referenciarse desde este archivo.
