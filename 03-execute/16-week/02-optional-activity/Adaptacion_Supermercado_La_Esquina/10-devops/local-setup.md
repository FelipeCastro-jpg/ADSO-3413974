## Requisitos

- Equipo de cómputo de gama económica (mínimo recomendado según el framework elegido).

1. Clonar/copiar el proyecto en el equipo.
2. Instalar dependencias del proyecto.
3. Configurar la base de datos local.
4. Ejecutar la aplicación y verificar que el módulo de ventas funcione correctamente.
