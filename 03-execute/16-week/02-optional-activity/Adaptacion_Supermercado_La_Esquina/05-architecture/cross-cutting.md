## Seguridad

- Acceso al sistema mediante usuario y contraseña.
- Solo el rol administrador puede editar precios, eliminar productos o gestionar usuarios.

## Manejo de errores

- Validaciones antes de registrar una venta (stock suficiente, datos completos).
- Mensajes claros y sencillos para usuarios sin experiencia técnica.

## Respaldo de información

- Copias de seguridad automáticas de la base de datos (diarias).

## Auditoría

- Cada venta y cambio de producto queda registrado con el usuario que lo realizó y la fecha/hora.
