# Gestión de incidentes

> Estado: 🟢 | Última actualización: 2026-07-05
> Autor: Andrés Felipe Castro Bedoya | Equipo: Andrés Felipe Castro Bedoya


| Incidente | Acción inmediata |
|-----------|-------------------|
| El sistema no enciende / no abre | Reiniciar el equipo; si persiste, restaurar copia de seguridad |
| El corte de caja no coincide | Revisar ventas registradas manualmente ese día y fiados pendientes |
| Pérdida de datos | Restaurar la última copia de seguridad disponible |
| Usuario olvida su contraseña | El administrador la restablece desde el módulo de usuarios |
