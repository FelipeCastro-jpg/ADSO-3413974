# Observabilidad

> Estado: 🟢 | Última actualización: 2026-07-05
> Autor: Andrés Felipe Castro Bedoya | Equipo: Andrés Felipe Castro Bedoya


Dado que es una aplicación local de un solo equipo, la "observabilidad" se limita a:

- Registro (log) interno de ventas, cambios de producto y accesos, con fecha, hora y usuario.
- Revisión periódica de este registro por el administrador para detectar errores o usos inusuales.
