# Revisión de código

> Estado: 🟢 | Última actualización: 2026-07-05
> Autor: Andrés Felipe Castro Bedoya | Equipo: Andrés Felipe Castro Bedoya


Al ser un proyecto individual de un solo desarrollador, la revisión de código se hace mediante autochequeo antes de cada entrega, verificando:

- Que el código siga una estructura clara y comentada donde sea necesario.
- Que cada nueva funcionalidad se pruebe contra los requerimientos del SRS antes de darla por terminada.
- Que no queden datos de prueba o contraseñas de ejemplo en el código final.
