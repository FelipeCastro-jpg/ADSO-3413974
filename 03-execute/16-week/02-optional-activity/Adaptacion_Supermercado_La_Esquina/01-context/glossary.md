# Glosario

> Estado: 🟢 | Última actualización: 2026-07-05
> Autor: Andrés Felipe Castro Bedoya | Equipo: Andrés Felipe Castro Bedoya


| Término | Definición | Contexto |
|---------|------------|----------|
| POS | Point of Sale, punto de venta: módulo donde se registran las ventas | Sistema |
| Fiado / Crédito | Venta que el cliente paga después, queda registrada como deuda | Negocio |
| Corte de caja | Comparación entre el dinero físico en caja y lo registrado en el sistema al cierre del día | Negocio |
| Tiquete de venta | Comprobante impreso o digital que se entrega al cliente tras una compra | Negocio |
| Stock | Cantidad disponible de un producto en inventario | Inventario |
| Inventario | Registro de todos los productos y sus cantidades disponibles | Sistema |
| Administrador | Rol con acceso completo: gestiona productos, precios, usuarios y reportes | Roles |
| Cajero | Rol que registra ventas en el punto de venta | Roles |
| SKU / Código de producto | Identificador único de cada producto en el catálogo | Inventario |
