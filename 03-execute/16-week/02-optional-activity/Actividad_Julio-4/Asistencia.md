# Asistencia

## Planteamiento general

Se requiere un sistema que permita registrar la asistencia de manera más eficiente (sin contar el uso de Sofia Plus).

## Requisitos

### Requisitos funcionales

- **RF01:** El sistema debe permitir al instructor registrar la asistencia de los aprendices por ficha y fecha.
- **RF02:** El sistema debe permitir al aprendiz confirmar su propia asistencia mediante un código o QR.
- **RF03:** El sistema debe generar reportes de asistencia por aprendiz, ficha o periodo.
- **RF04:** El sistema debe permitir registrar un aprendiz consultando automáticamente sus datos en Sofia Plus, evitando la doble digitación.

### Requisitos no funcionales

- **RNF01:** El sistema debe responder al registrar o consultar asistencia en menos de 3 segundos.
- **RNF02:** El sistema debe ser accesible desde dispositivos móviles y de escritorio con conexión a internet.
